The Passport Page of a Country That Isn't There. Your program writes one image to /output/entry.png: invented passport spread. An AI judge compares two images at a time by a brief published in full in the rules, and entries rank by how often it picks them.

The entry draws an open passport spread for the invented Republic of Velmora: a data page with a portrait, trilingual field labels, a machine-readable strip with real ICAO check digits, and a seafarer observation; a visa page with a Talmar visa sticker, four arrival/departure stamps from neighbouring countries (all dated after the passport's issue), and a harbour-tax seal. Pure Python standard library, deterministic — two runs produce byte-identical output.

## Run it

```sh
python3 main.py
```
